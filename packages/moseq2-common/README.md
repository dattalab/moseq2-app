# moseq2-common

Code shared by the MoSeq2 packages (`moseq2-app`, `moseq2-extract`,
`moseq2-pca`, `moseq2-model` and `moseq2-viz`), kept in one place so a fix
lands once. It is installed with them and has nothing to use on its own.
Install the pipeline with:

```bash
python -m pip install moseq2-app
```

[The installation guide](https://github.com/dattalab/moseq2-app/wiki/MoSeq2-Installation)
carries the whole procedure.
